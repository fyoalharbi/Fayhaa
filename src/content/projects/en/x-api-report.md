## What it does

A Python application that builds on **X's Engagement API** to generate a report with the important KPIs and metrics:

1. **Filters tweets** to the ones that matter for the report.
2. **Analyzes engagement metrics** for those tweets.
3. **Generates charts** and a final **insights report**.

## Where it was used

Built during my time at Hackathonat, where I also analyzed monthly data to report progress against monthly goals.

*Built between September 2023 and April 2024.*
