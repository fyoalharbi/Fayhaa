من بدأت رحلتي بالـ Vibe Coding أكبر مشكلة كنت أواجها هي لكاعة الـ AI، وكلاود كود بالتحديد 🤦‍♀️

أسوي ملف كامل بالـ Requirements وأعطيه له، ويسوي لي شيء ما يعكس إلا 10% من المطلوب ويقول لي خلصت. هذا غير إنه كل ما أطلب منه حاجة يتلكع ويقول لي أسويها (ماني عبد أبوك لا تأمر ولا تنهى).

وطحت على إطار عمل اختصر علي هالكم الهائل من إقناع AI كسول إنه ينجز لي اللي أبي.

## GSD (Git. Ship. Done) 🚀

هو إطار لعمل وكلاء الذكاء الاصطناعي عن طريق تكوين **Phases** للعمل. عدد الـ Phases يعتمد على حجم العمل حقك وحرصك على تفاصيله. بكل Phase راح يكون فيه Loop تتكرر فيه نفس الخطوات:

1. **Discuss:** يناقشك بتفاصيل العمل عشان يرسم خطة صحيحة.
2. **Plan:** يسوي لك بحث ويتأكد لك من الخطة.
3. **Execute:** يبدأ بتنفيذ الخطط بشكل متوازي.
4. **Verify:** يتأكد لك من اللي انبنى ويحل لك المشاكل.
5. **Ship:** يسوي لك Pull Request ويأرشف الـ Phase ثم ينتقل للي بعده.

المميز أيضاً إنه يعطيك خيار تختار المودل المناسب لكل Step. فعلى سبيل المثال تبي التخطيط Opus 4.8 ولكن التنفيذ Sonnet 4.6، يمديك تسويه بالراحة.

## مشكلة التوقفات و /Goal

المشكلة اللي واجهتني بعدها هي توقفاته عشان أسوي Clear للـ Context أو Approve لبعض الأشياء. وهنا نجي لبعض الـ Features الموجودة في Claude Code مثل **`/goal`**: أسوي Set للـ Goal إنه يكون *Finishing all phases*، وبكذا يبتل ماشي على خطتي إلا لو احتاج input مني أو تأكيد على حاجة.

أتمنى تفيدكم تجربتي، وإذا عندكم Tips ثانية ياليت تشاركونا.
